# ⛰️ Nan Beyond Seasons - Local-Verse Engine

**Nan Beyond Seasons (Local-Verse Engine)** เป็นแพลตฟอร์มนวัตกรรม B2B2C อัจฉริยะที่ถูกพัฒนาขึ้นภายใต้การแข่งขัน **Nan Beyond Seasons Hackathon 2026** โดยทีม **HACK RMUTL** มีเป้าหมายสูงสุดเพื่อนำเทคโนโลยีปัญญาประดิษฐ์ (AI) และแนวคิด Design Thinking มาขับเคลื่อนการท่องเที่ยวเมืองรองในจังหวัดน่าน (เช่น อำเภอปัว, อำเภอบ่อเกลือ และตัวเมืองน่าน) ให้สามารถสร้างรายได้และกระจายเม็ดเงินสู่ชุมชนได้ตลอดทั้ง 12 เดือน โดยเฉพาะในช่วงฤดูฝน (Green Season) หรือช่วง Low Season โดยไม่ต้องพึ่งพาเพียงแค่ฤดูกาลท่องเที่ยวหลัก (High Season) ในหน้าหนาวเท่านั้น

---

## 🎯 แนวคิดและที่มาของโครงการ (Core Concept)
เสน่ห์ของจังหวัดน่านไม่ได้หมดไปเมื่อสิ้นสุดหน้าหนาว แต่ในฤดูฝน "น่าน" เต็มไปด้วยความเขียวขจีของทุ่งนาขั้นบันได สายหมอกลอยเอื่อย และวิถีชีวิตที่สงบสุข ทว่าที่ผ่านมาผู้ประกอบการรายย่อย โฮมสเตย์ ร้านอาหาร และวิสาหกิจชุมชนยังขาดเครื่องมือทางดิจิทัลที่มีประสิทธิภาพในการดึงดูดนักท่องเที่ยวกลุ่มเฉพาะ (เช่น Digital Nomad, นักท่องเที่ยวสายกรีน) ในช่วงเวลาดังกล่าว

**Nan Local-Verse Engine** จึงสร้างขึ้นเพื่อทำหน้าที่เป็น "ตัวกลางทางเทคโนโลยี" ที่ประสานงานข้อมูลสภาพอากาศ วัฒนธรรม และอาหารท้องถิ่น เข้ากับระบบเศรษฐกิจชุมชนผ่าน 2 ช่องทางหลัก:
1. **B2B Command Center (ฝั่งผู้ประกอบการ):** ใช้ระบบ Context-Aware AI ช่วยคิดค้นและสร้างแคมเปญการตลาดอัจฉริยะแบบ Real-time ให้สอดคล้องกับสภาพอากาศ เช่น เมื่อฝนตกหนัก AI จะเสนอแคมเปญดึงนักท่องเที่ยวเข้ามาทำกิจกรรมในร่มเพื่อหลบฝน
2. **B2C Gamification App (ฝั่งนักท่องเที่ยว):** เปลี่ยนการเดินทางให้เป็นเกมตามล่าสมบัติ (Quest & Rewards) สุ่มสแกนรับภารกิจในพื้นที่เมืองรองเพื่อรับส่วนลดและช่วยกระจายการท่องเที่ยว

## ⚡ 4 เสาหลักการขับเคลื่อนนวัตกรรม (4 Pillars)
แพลตฟอร์มนี้พัฒนาขึ้นเพื่อตอบโจทย์ตัวชี้วัดความสำเร็จ (KPIs) ของโครงการอย่างครบถ้วนผ่าน 4 มิติหลัก:
* **🌾 ด้านชุมชน (Community):** ชูโรงอัตลักษณ์ท้องถิ่น เช่น นาขั้นบันไดของปัว และวิถีการทำเกลือสินเธาว์ภูเขาของบ่อเกลือ มาแปลงเป็นภารกิจสิทธิประโยชน์เพื่อกระจายตัวนักท่องเที่ยวออกจากเมืองหลัก
* **💚 ด้านสุขภาพ (Wellness):** ออกแบบกิจกรรมแนวสโลว์ไลฟ์เพื่อบำบัดความเครียด (Workation) ท่ามกลางธรรมชาติน่านในวันธรรมดา เหมาะกับกลุ่มที่มองหาความเงียบสงบ
* **🌧️ ด้านภูมิอากาศ (Weather AI):** แก้ปัญหาจุดสลบช่วงหน้าฝน/หน้าโลว์ ด้วย AI พยากรณ์อากาศที่ช่วยกระตุ้นการขายอย่างยืดหยุ่นตามสภาพการณ์จริง
* **🍲 ด้านอาหาร (Local Cuisine):** เสิร์ฟเควสสุ่มเมนูเด็ดท้าสายฝน เช่น โกโก้แท้น่านร้อนๆ, ข้าวซอยไก่ หรือลาบคั่วสูตรมะแขว่น เพื่อเพิ่มมูลค่าวัตถุดิบและอาหารพื้นถิ่น

## 🏗️ สถาปัตยกรรมระบบ (System Architecture)
โปรเจกต์นี้ถูกออกแบบโครงสร้างแบบ Monorepo / Multi-folder ประกอบด้วยระบบหน้าบ้านและหลังบ้านที่เชื่อมต่อกันอย่างสมบูรณ์:
[ Client: Next.js 14 ] 
         │
         ├── (REST API via HTTP) ──> [ Server: FastAPI ] ──> Google Gemini AI
         │                                   (Core Campaign Engine)
         └── (Direct Integration) ──> [ Database: Supabase (PostgreSQL) ]
                                             (Shops, Campaigns, Quests Tables)

1. **Frontend (`/client`):** พัฒนาด้วย Next.js (App Router) ร่วมกับ Tailwind CSS และ Lucide Icons มีระบบ Dynamic Theme (Dark/Light mode) ที่สวยงาม พร้อม CSS Keyframes สำหรับงาน Animation ที่สะท้อนจิตวิญญาณธรรมชาติของน่าน (สายหมอกลอยเอื่อยและฝูงนกกระยางขาว)
2. **Backend Engine (`/server`):** พัฒนาด้วย FastAPI โครงสร้างแบบ Modular Design ที่รองรับการขยายตัว ควบคุมการวิเคราะห์ข้อมูล Brief เพื่อส่งต่อไปยัง Generative AI ในการคิด Campaign รูปแบบต่างๆ
3. **Database Setup:** ใช้งาน Supabase (PostgreSQL) ในการเก็บข้อมูลโครงสร้างร้านค้า (`stores`), แคมเปญจาก AI (`campaigns`) และระบบเควสล่ารางวัล (`quests`)
